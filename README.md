# Photo Booth teacher day SMK ARRAHMAN

Aplikasi photobooth retro yang berjalan 100% di browser (tanpa backend). Foto tidak pernah diunggah ke server.

## Menjalankan di komputer
```bash
npm install
npm run dev
```
Buka http://localhost:3000 (kamera hanya jalan di localhost atau HTTPS).

## Deploy
Hubungkan repo ini ke Vercel (Import Project). Tidak perlu pengaturan tambahan.
